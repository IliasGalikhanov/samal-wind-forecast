# Модель мощности турбин

**Происхождение результатов.** Числа реального эксперимента ниже получены на непубличном исходном датасете. CSV, модели и детальные результаты этого эксперимента не распространяются. Публичный синтетический демосценарий проверяет работоспособность конвейера; его метрики нельзя сравнивать с точностью на реальной ВЭС.

## Данные и цель

CSV содержит время, средний ветер, мощность и температуру. Названия столбцов сопоставляются при импорте; ID строки не используется как признак. Турбина выбирается из пользовательского каталога. Проценты делятся на 100; кВт и МВт — на указанную номинальную мощность в согласованных единицах. Для полного часа требуется `60 / sample_minutes` уникальных измерений, где интервал задаётся для турбины (5/10/15/20/30/60 минут). Неполные часы сохраняются как пропуски. Цель — средняя нормализованная мощность в диапазоне 0–1, в UI — 0–100%.

Время измерений интерпретируется в настроенном часовом поясе IANA; для исходного эксперимента принято Asia/Almaty. Исторические изменения смещения учитывает tzdata. Номинальная мощность задаётся пользователем при импорте кВт/МВт; для исходного эксперимента она неизвестна. Прогноз остаётся нормализованным, физические единицы энергии не рассчитываются.

## Признаки и модели v4

| Модель | Признаки |
|---|---|
| CatBoost с историей и погодой | 92 признака истории и календаря + 5 погодных |
| CatBoost только с погодой | 6 признаков календаря, турбины и горизонта + 5 погодных |
| CatBoost только с историей | 92 признака |
| Persistence | Последняя доступная мощность |
| Сезонный профиль | Прошлые значения по календарю |

Погода: скорость ветра на 100 м, температура на 2 м, sin/cos направления ветра и куб скорости. В v4 удалён признак архивного смещения выпуска: актуальный API не предоставляет эквивалентное значение. Поэтому модели v3 не используются как модели v4 без переобучения.

CatBoost: 320 деревьев, depth=6, learning_rate=0.05, l2_leaf_reg=8, loss=MAE, seed=42, 4 потока. Финальные параметры также сохраняются в `result.json`.

## Обучение и выбор

Используется до 730 дней доступной истории с архивными прогнозами Open-Meteo ICON Global. Обучающие моменты идут через 12 часов, горизонт — 48 часов. Признаки истории берутся только до origin; обучающие цели — строго до cutoff. Для обучения требуется не менее 90 дней подходящей истории после января 2024 года.

Перед каждым из четырёх 14-дневных отрезков модели обучаются заново. Все методы сравниваются на одинаковых парах прогноз/факт. Побеждает минимальная MAE, затем RMSE. Последние 14 дней используются как исторический аудит. Этот период уже рассматривался при разработке, поэтому он не является новым независимым тестом.

Затем выбранные модели обучаются на доступной истории целиком и сохраняются рядом с входными данными. В v5 обучение отделено от прогнозирования: пакет содержит CatBoost-модели, погодный снимок, результаты валидации и исторического аудита. Последующий прогноз загружает совместимый пакет и получает новую погоду без повторного обучения.

## Сохранённые модели v5

`runtime/models/` содержит локальный кеш. Ключ включает SHA-256 снимка измерений, горизонт оценки, координаты, часовой пояс, источник (синтетика или Open-Meteo), признаки, параметры, код ML-конвейера и версии зависимостей. Изменения измерений, конфигурации или кода требуют нового обучения; смена origin и обновление прогноза погоды — нет. Для принудительного обновления: `python scripts/forecast.py --force-retrain` или `force_retrain: true` в POST `/api/runs`.

Каждый файл пакета проверяется по SHA-256, модели загружаются CatBoost. Повреждённый или неполный пакет не используется. Указатель новой версии публикуется атомарно после сохранения всех файлов; неудачный расчёт не удаляет прежние версии. Кеш предназначен для локальных файлов приложения, не для загрузки моделей из недоверенных источников.

В результате записываются `training.bundle_id`, `trained_at`, `reused` и `input_sha256`. При повторном применении метрики относятся к исходному обучению; это не новая оценка на свежем факте. Исторический режим без погоды (`worker.py`) остаётся отдельным учебным конвейером и обучается при каждом запуске.

В синтетическом режиме используется тот же выбор моделей и те же параметры CatBoost. И измерения, и погода вымышлены (`ml/synthetic.py`), запросов во внешнюю сеть нет. Признак `data_source=synthetic` сохраняется в JSON и экспорте. Эти демонстрационные зависимости специально доступны для обучения и не моделируют все сложности реальной ВЭС.

## Текущий прогноз

Для будущих часов запрашивается `https://api.open-meteo.com/v1/forecast`, модель `icon_global`. Прогноз начинается со следующего полного часа. Ответ и время получения сохраняются в `weather-live.json`. Кеш актуального ответа действует до одного часа.

Историческая валидация использует Previous Runs API с 12-часовым запасом, актуальный прогноз — последний ответ Forecast API. Разница заблаговременности источников может влиять на качество; историческая MAE не является измеренной ошибкой текущего прогноза. Точное время инициализации погодной модели текущий API не сообщает.

Если свежих измерений нет, используется выбранный резерв без свежих лагов: погодный CatBoost или сезонный профиль. Название фактически применённой модели записывается для каждой строки. Прогноз не учитывает неизвестные текущие остановки турбин.

## Результаты

В UI и `result.json` сохраняются MAE, RMSE, число проверенных пар, оценки по турбинам и горизонтам. Метрики в JSON имеют шкалу 0–1; интерфейс умножает ошибки на 100 и показывает процентные пункты. 19,5 п.п. ошибки не означает 80,5% точности.

Числа v3 из истории разработки относятся к старому набору признаков. Результаты v4 следует брать из запуска с `pipeline_version=live-weather-4fold-v4` и его хешем входа. Факта за прогнозируемые будущие часы нет, поэтому `future_accuracy_confirmed=false`.

### Измеренный запуск v4

Запуск `1791031571181284200`, 3 октября 2026 года. SHA-256 снимка измерений: `3aeba5ded04b95f75a73af5e4f08d9aeeb0b03f302971291e5030bc222714852`.

| Метод | MAE на 4 отрезках, п.п. | MAE 18–31 января, п.п. |
|---|---:|---:|
| CatBoost с погодой и историей | 19,15 | 19,45 |
| CatBoost только с погодой | 19,20 | 18,67 |
| CatBoost только с историей | 30,15 | 29,80 |
| Последнее измерение | 33,17 | 39,36 |
| Сезонный профиль | 34,57 | 30,79 |

Основной метод выбран по валидации: погода и история. Для текущего прогноза применён погодный CatBoost, поскольку свежих измерений нет. Результат содержит 96 значений с 3 октября 18:00 до 5 октября 17:00 Asia/Almaty; диапазон 9,06–100%. Это проверка выполнения сценария, а не измерение точности октябрьского прогноза.
