# Сторонние компоненты и данные

MIT в корне относится к собственному коду, документации и синтетическому генератору SAMAL. Сторонние компоненты сохраняют свои лицензии. Исходные данные хакатона, документы организаторов, приватные модели и погодные снимки под MIT проекта не распространяются и в репозиторий не включены.

| Компонент | Лицензия / источник |
|---|---|
| React, React DOM, Recharts | MIT, тексты из установленных npm-пакетов |
| Lucide React | ISC, текст из установленного npm-пакета |
| TypeScript | Apache-2.0 |
| Vite и React plugin | MIT |
| modernc.org/sqlite и modernc.org/libc | BSD-3-Clause; зависимые Go-модули — по собственным лицензиям |
| CatBoost | [Apache-2.0](https://github.com/catboost/catboost/blob/master/LICENSE) |
| NumPy, pandas, SciPy, scikit-learn | BSD-3-Clause; встроенные компоненты указаны в текстах поставки |
| Другие Python и npm зависимости | Декларации и тексты из установленных пакетов в сборнике ниже |
| Open-Meteo / DWD ICON Global | [CC BY 4.0 и условия API](https://open-meteo.com/en/terms); только обычный режим |

Версии закреплены в `frontend/package-lock.json`, `go.mod` / `go.sum` и `ml/requirements.lock.txt`. Копии имеющихся текстов лицензий и уведомлений собраны в [licenses/dependencies.txt](licenses/dependencies.txt). Лицензия CatBoost дополнительно сохранена из официального репозитория в [licenses/catboost-LICENSE](licenses/catboost-LICENSE), поскольку установленный wheel не содержит отдельного файла лицензии.

Обновление сборника после установки зависимостей: `python scripts/collect_notices.py`. При изменении зависимостей необходимо пересобрать уведомления. Это инвентаризация установленных пакетов, а не юридический аудит. В Docker уведомления проекта находятся в `/usr/share/doc/samal`; уведомления Python-пакетов и базового Debian-образа также остаются на своих штатных местах.

В деморежиме измерения, погода и ошибки прогноза генерируются собственным кодом; исходные CSV и Open-Meteo не используются. Названия HackAlem AI, Astana Hub, OpenAI, Open-Meteo и других сторон упоминаются для указания происхождения задачи и инструментов; проект не заявляет их одобрение или партнёрство.
